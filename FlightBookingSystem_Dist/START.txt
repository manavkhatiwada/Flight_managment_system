Welcome to the Flight Booking Management System!

This document explains how to build and run the application.

═══════════════════════════════════════════════════════════════════════════════
                              QUICK START
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Build the Project
────────────────────────
  Double-click: build.bat

  This will:
  • Compile all 23 Java source files
  • Generate 29+ .class files in bin/ directory
  • Take about 5 seconds
  • Show "Build completed successfully!" when done

STEP 2: Run the Application
──────────────────────────
  Double-click: run.bat

  This will:
  • Launch the console application
  • Load sample data automatically
  • Show "Flight Booking System" prompt
  • Wait for your commands

STEP 3: Try Commands
────────────────────
  Type these commands at the prompt (>):

  listflights           - View all flights
  listcustomers        - View all customers
  addbooking 1 1       - Create booking (Customer 1 → Flight 1)
  showflight 1         - Show flight #1 details
  showcustomer 1       - Show customer #1 details
  loadgui              - Launch GUI version
  help                 - Show all commands
  exit                 - Quit application

                          TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Q: build.bat doesn't work
A: Ensure Java is installed
   Open Command Prompt and type: java -version

Q: run.bat doesn't work
A: Run build.bat first to compile

Q: GUI doesn't appear
A: Type "loadgui" in the console version
   Check that Swing is available

Q: Data not saving
A: Ensure resources/data/ directory exists and is writable

Q: Compilation errors
A: Make sure you're using Java 8 or higher
